# vite-basic

A minimal Vue 3 + Vite app: one component (`Hero`), the editor, and the renderer, side by side.

This is also the Quickstart in the docs, word for word and file for file. Its `src/` is imported by `getting-started/quickstart.md` directly, so the two cannot drift: a test (`apps/docs/tests/vite-basic-frozen.test.ts`) fails if the page and this example's files ever stop matching.

Because of that, this example stays minimal on purpose. A feature demo belongs in [layouts-and-slots](../layouts-and-slots), not here.

## Run it

```sh
npm install
npm run dev
```
